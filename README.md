# วิธีติดตั้ง Apps Script (ส่งรูปเข้า Google Drive + ลิงก์ลง Google Sheet)

ไฟล์ `Code.gs` ในโฟลเดอร์นี้ คือโค้ดฝั่ง Google ที่ทำให้ฟอร์ม:
- ส่ง **ข้อความ** ของน้องลง Google Sheet (เหมือนเดิม)
- ส่ง **รูปทุกใบ** ขึ้น Google Drive โดยจัดโฟลเดอร์:
  `พอร์ตน้อง / [ชื่อนักเรียน] / [หมวด] / ไฟล์รูป`
- เขียน **ลิงก์รูปทุกใบ** ลงแถวเดียวกับข้อมูลน้องในชีต (คลิกเปิดดูได้เลย)

ทำตามทีละขั้นนะครับ (ทำครั้งเดียวจบ) 👇

---

## ขั้นที่ 1 — เปิด Apps Script จากในไฟล์ Google Sheet
1. เปิด **Google Sheet** ที่ใช้เก็บข้อมูลพอร์ตอยู่แล้ว (ไฟล์เดิมที่ข้อมูลน้องเคยเด้งเข้า)
2. ที่แถบเมนูด้านบน เลือก **ส่วนขยาย (Extensions) → Apps Script**
3. จะเปิดหน้าต่างเขียนโค้ดขึ้นมา จะเห็นไฟล์ชื่อ `Code.gs` (หรือ `โค้ด.gs`)

> 💡 การเปิดผ่าน Sheet แบบนี้ (script แบบผูกกับชีต) ทำให้ **ไม่ต้อง** ใส่ค่า `SPREADSHEET_ID`
> ปล่อยเป็น `''` ไว้ได้เลย

---

## ขั้นที่ 2 — วางโค้ดใหม่
1. ใน Apps Script ให้ **ลบโค้ดเก่าทั้งหมด** ในไฟล์ `Code.gs` ออก
2. เปิดไฟล์ `Code.gs` (ในโฟลเดอร์นี้) **คัดลอกทั้งหมด** ไปวางแทน
3. (ถ้าต้องการ) ปรับค่าด้านบนของไฟล์:
   - `ROOT_FOLDER_NAME` = ชื่อโฟลเดอร์หลักใน Drive (ค่าเริ่มต้น `พอร์ตน้อง`)
   - `SHEET_NAME` = ชื่อแท็บชีตที่จะเก็บข้อมูล (ค่าเริ่มต้น `ข้อมูลพอร์ต`)
   - `MAKE_LINKS_PUBLIC` = `true` ให้ลิงก์รูปเปิดดูได้ทันที / `false` เฉพาะเจ้าของ
4. กด **บันทึก** (รูปแผ่นดิสก์ 💾 หรือ Ctrl+S)

---

## ขั้นที่ 3 — Deploy เป็น Web App
1. มุมขวาบน กด **Deploy → New deployment** (ปรับใช้ → การปรับใช้ใหม่)
2. ตรง **Select type** (เลือกประเภท) กดรูปเฟือง ⚙️ แล้วเลือก **Web app**
3. ตั้งค่า:
   - **Description**: อะไรก็ได้ เช่น `พอร์ตน้อง v2`
   - **Execute as** (ทำงานในนามของ): **Me (ตัวฉันเอง)**
   - **Who has access** (ใครเข้าถึงได้): **Anyone (ทุกคน)**  ← สำคัญมาก ต้องเลือกอันนี้
4. กด **Deploy**
5. ครั้งแรกจะขอ **อนุญาตสิทธิ์ (Authorize access)**:
   - กดอนุญาต → เลือกบัญชี Google ของตัวเอง
   - ถ้าเจอหน้า "Google hasn't verified this app" ให้กด **Advanced → Go to ... (unsafe)** แล้วกด **Allow**
   - (ปลอดภัย เพราะเป็นสคริปต์ของเราเอง)
6. เสร็จแล้วจะได้ **Web app URL** หน้าตาแบบนี้:
   ```
   https://script.google.com/macros/s/AKfycb..................../exec
   ```
   👉 **คัดลอก URL นี้ไว้**

> ⚠️ ทุกครั้งที่แก้โค้ด แล้วอยากให้มีผล ต้อง **Deploy ใหม่**
> แนะนำใช้ **Manage deployments → (ดินสอ ✏️) แก้ deployment เดิม → Version: New version → Deploy**
> วิธีนี้ **URL จะไม่เปลี่ยน** (ถ้ากด New deployment ใหม่ทุกครั้ง URL จะเปลี่ยน ต้องเอาไปแก้ในฟอร์มใหม่)

---

## ขั้นที่ 4 — เอา URL ใหม่ไปใส่ในฟอร์ม
1. เปิดไฟล์ **`index.html`** (ในโปรเจกต์เว็บ)
2. ค้นหาคำว่า `SHEET_WEB_APP_URL` (อยู่ประมาณกลาง ๆ ในส่วน `<script>`)
3. จะเห็นบรรทัดนี้:
   ```js
   var SHEET_WEB_APP_URL='https://script.google.com/macros/s/AKfycby5.........../exec';
   ```
4. แก้ค่าในเครื่องหมาย `'...'` ให้เป็น **URL ใหม่** ที่คัดลอกมาจากขั้นที่ 3
5. บันทึกไฟล์ แล้ว push ขึ้น GitHub (GitHub Pages จะอัปเดตให้เอง)

---

## ขั้นที่ 5 — ทดสอบ
1. เปิดเว็บฟอร์ม กรอกข้อมูล + แนบรูปสัก 1-2 ใบ
2. กดปุ่ม **ส่งข้อมูล**
   - ระบบจะดาวน์โหลดไฟล์ ZIP ให้ (สำรองในเครื่อง)
   - แล้วขึ้นข้อความ `กำลังส่งรูปขึ้น Google Drive x/N` จนครบ
3. เปิด **Google Drive** → จะเห็นโฟลเดอร์ `พอร์ตน้อง / [ชื่อนักเรียน] / [หมวด] / รูป`
4. เปิด **Google Sheet** → จะเห็นแถวใหม่ มีข้อมูลน้อง + คอลัมน์ `ลิงก์รูปทั้งหมด` (คลิกลิงก์เปิดดูรูปได้)

---

## เกร็ดแก้ปัญหา
- **รูปไม่ขึ้นใน Drive / ชีตไม่มีลิงก์** → มักเป็นเพราะ **Who has access ไม่ได้ตั้งเป็น Anyone** หรือ **ยังไม่ได้ Deploy ใหม่หลังแก้โค้ด** หรือ **ยังไม่ได้เอา URL ใหม่ไปใส่ในฟอร์ม**
- **รูปเยอะแล้วช้า** → ปกติครับ เพราะส่งทีละใบ (กันข้อมูลใหญ่เกิน) รอจนข้อความขึ้นครบ `x/N` แล้วค่อยปิดหน้า
- **ลิงก์เปิดไม่ได้ (ถูกจำกัดสิทธิ์)** → ตั้ง `MAKE_LINKS_PUBLIC = true` หรือถ้าองค์กรบล็อกการแชร์สาธารณะ ให้เจ้าของชีต (คนเดียวกับเจ้าของ Drive) เป็นคนคลิกเปิดเอง
- **อยากเก็บรูปต้นฉบับความละเอียดเต็ม** → ในไฟล์ `index.html` ฟอร์มจะย่อรูปที่ใหญ่เกิน ~1.5MB ให้อัตโนมัติ (กว้าง/สูงไม่เกิน 1600px) ถ้าไม่อยากให้ย่อ บอกได้ เดี๋ยวปรับให้
